# TheoJoubert

## Social Media Agent for Small Businesses

This repository now includes a lightweight social media planning agent aimed at small businesses.

### What it does
- Builds a 7-day content plan across selected social platforms
- Generates concise caption drafts with hashtags and a call-to-action
- Keeps output deterministic and dependency-free for easy local use

### Run
```bash
python /home/runner/work/TheoJoubert/TheoJoubert/social_media_agent.py
```

### Test
```bash
python -m unittest discover -s /home/runner/work/TheoJoubert/TheoJoubert/tests -p "test_*.py"
```
